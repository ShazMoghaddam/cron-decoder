    Reference

    FieldRangeNames
    • *  any value — every unit in the field
    • ,  list — e.g. 1,15,30
    • -  range — e.g. 9-17
    • /  step — e.g. */15 or 0-30/5
    • ?  any value — treated as * in the day fields
    • Shortcuts — @hourly @daily @weekly @monthly @yearly @reboot
    • Six fields — a leading field adds seconds
    • Day match — if both day-of-month and day-of-week are set, either one matching triggers the run
